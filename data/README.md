# Character-set data

`joyo_kanji.txt` contains 2,136 unique Unicode scalars. Source: `hiroshi-manabe/Joyo-Kanji-List/joyo.tsv`, first-column sequence (blob SHA `6866de1edafe36fa7473e5a6580c5443e2b793e0`). See THIRD_PARTY_NOTICES.md.

The JIS X 0208 level-1/level-2 set is derived from the Python `iso2022_jp` codec, 6,355 mapped characters; it is not a hand-maintained external list.
